# HondataDash V1.0

V1.0 is the original stable release in the consolidated public history and corresponds technically to the previously validated V2.7.0 baseline.

Core capabilities include FlashPro Bluetooth SPP communication, approximately 50 Hz acquisition, an 800×480 landscape dashboard, eight primary cards, MAX/MIN and HI/LO extrema, basic DFCO/SYNC semantics, semantic main-value colors, reconnect/session recovery and defensive NaN/invalid-frame handling.
