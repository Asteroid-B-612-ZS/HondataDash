# HondataDash V2.0.1-internal.1

> V2.0 后第一个内部语义验证版本。不是公开 Release，不替代 V2.0 Frozen Reference。

## 版本身份

- versionName: `2.0.1-internal.1`
- versionCode: `45`
- applicationId: `io.github.asteroidb612zs.hondatadash.internal`
- base: current `master`, whose production code is identical to public `v2.0` plus regression-manifest files
- intended branch: `internal/v2.0.1-it1`

## 本轮目标

本轮只针对 V2.0 复核中权重最高且有代码证据的问题进行验证，不做 UI 重构，也不改 BluetoothSource、HondataProtocol、MAP/RPM realtime、卡片布局或 5+5 Shift Indicator。

### 1. ThermalContext 与 MainState 解耦

V2.0 的 `WARMUP` 与 `WOT` 同属互斥 MainState；冷机快速进入 WOT 时，主状态会正确保留 WOT，但历史/显示层如果仅用 `MainState.WARMUP` 判断热状态，会把 WOT 错当成已经热机。

本版本新增独立 `ThermalContext`：

- UNKNOWN
- COLD
- WARMING
- READY

它每帧独立于 WOT/NORMAL/IDLE/DFCO 更新，因此能够表达 `WOT + COLD`。为降低回归风险，`MainState.WARMUP` 仍保留，原 MainState 判定顺序不变。

最终收口后删除语义模糊的 `isWarmup()`，也不保留未使用的 `isWarmupMainState()`；消费端必须显式调用 `isThermallyReady()` 或 `isThermalWarmup()`。MainState 如需判断则直接读取 `state.main`。

### 2. Fuel Pressure persistence：reset → pause

V2.0 在 SHIFT 或非 FIRING_VALID 状态下直接 `reset()` 低燃压持续时间。这会把“当前不可可靠观察”解释成“异常已经消失”。

本版本改为 observed-time evidence：

- observable + low：累计低压可观察时间；
- unobservable：短时暂停累计，不增加时间；连续不可观察达到 8 s 后旧 evidence 过期（stale，不等于 healthy）；
- observable + healthy：明确清除证据；
- 300 ms 高需求 / 800 ms 普通需求阈值保持不变。

目标是验证：正常换挡继续不产生 false alert，同时持续真实低压不能被频繁换挡无限清零。

### 3. Semantic cleanup

- 删除从未有赋值点的 `Modifier.RPM_DIP`。
- `isShift()` 统一以 `ShiftPhase != NONE` 为事实来源。
- 删除 `CombustionDisplayAdmission.updateStrim()` 内不可达的 `Modifier.SHIFT` 动态判断；SHIFT 已由上层 hardGuard 完整处理。
- 明确 `state.confidence` 是 MainState confidence，与 S.TRIM Trusted/Context/Low presentation weight 不是同一机制。

## 明确不改

- BluetoothSource / pairing / reconnect
- HondataProtocol framing
- SHIFT_ARMED / SHIFT_CONFIRMED 阈值与时序
- SHIFT / DFCO / OTHER_FUEL_CUT 分类本体
- A/F、IGN、S.TRIM recovery 常量
- S.TRIM 1.00 / 0.82 / 0.62 权重
- MAP/RPM realtime
- MainActivity 布局、卡片几何和颜色体系
- Semantic extrema 数值策略本身

## 新增测试目标

`verify_v201_internal_semantics.py` 检查：

1. ThermalContext 正交存在且在 MainState 判定前更新；
2. cold-WOT 可表达为 WOT + 非 READY thermal context；
3. RPM_DIP 不再存在；
4. S.TRIM SHIFT 死分支被删除；
5. Fuel Pressure 短时 unobservable 路径 pause，超过 8 s evidence-age 上限后 stale reset；
6. 合成场景：600 ms 可观察低压 + SHIFT + 200 ms 可观察低压，应在累计 800 ms 后报警；
7. 合成场景：SHIFT 后第一个可观察样本恢复正常，应清除旧证据而不报警。

## 验收原则

这是内部验证版本。只有同时满足下列条件，才有资格进入后续 V2.x 讨论：

- V2.0 既有 QA 全部保持 PASS；
- 新增 semantic refinement QA PASS；
- APK 编译、zipalign、v1/v2 signing、AAPT version identity PASS；
- 真实 V2 Regression Dataset v1.0 回归不恶化 Frozen Guardrails；
- 新增 false-negative / suppression-cost 指标得到可解释结果；
- 实车测试没有引入新的驾驶信息噪声。

V2.0 仍然是 Frozen Reference；该内部版本只用于验证假设。


## Pre-road-test semantic closeout (2026-09-18)

### Fuel-pressure evidence age

Core14 观察到 24 个低压 evidence pause：P50 0.98 s、P90 2.18 s、max 8.56 s。5/8/10 s 候选均保持 0 false alert；5 s 淘汰 2 个 pause，8 s 淘汰 1 个，10 s 淘汰 0 个。选择 **8 s TTL**：它大于已验证约 3.02 s SHIFT + <=0.85 s recovery 的两倍，同时能阻止唯一 >8 s 的陈旧 evidence bridge。

过期表示 evidence stale，不表示 pressure healthy；可观察健康帧仍是明确 counter-evidence。

### Calibration provenance and hot reconnect

已恢复 A/F 1400 ms、S.TRIM 1600 ms、SHIFT_ARMED 4%、SHIFT 3 s ceiling、fuel-cut 分类和 TIP_OUT 优先级的历史/物理依据注释。

热机连接/重连首帧 ECT >72°C 直接 READY 是有意设计：它是对已经热透发动机的直接观测；5 s confirmation 仅用于同一 session 内 COLD/WARMING -> READY 的动态跨阈值。
