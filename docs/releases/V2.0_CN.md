# 更新日志

## V2.0 — 语义仪表与 OEM 界面

V2.0 是当前代际版本，在 V1.0 稳定通信与数据显示基础上完成显示架构和 UI 的代际升级。

- OEM 风格 800×480 界面与 5+5 RPM Shift Indicator。
- SHIFT 与 DFCO / OTHER_FUEL_CUT 分离。
- A/F、IGN、S.TRIM 可信显示记忆与恢复门控。
- S.TRIM 解释可信度加权呈现。
- 所有主卡片继续保留双极值槽，并采用语义极值准入与参数级保持时间。
- ECT/IAT 避免冷启动低温污染有意义的 MIN。
- MAP 增压峰值和发动机真空低值分别按真实工况准入。
- A/F、IGN、S.TRIM 极值排除换挡、断油和明显瞬态污染。
- 燃油压力异常持续时间门控与 RAM 短时诊断记忆。
- applicationId 迁移至 `io.github.asteroidb612zs.hondatadash`。

## V1.0 — 初代稳定版本

V1.0 对应此前已经验证的 V2.7.0 稳定代码基线，是重新整理公开版本体系后的第一代正式版本。

主要能力包括 FlashPro 蓝牙 SPP 通信、约 50 Hz 数据读取、800×480 横屏仪表、8 个主数据卡片、MAX/MIN 与 HI/LO 极值、DFCO/SYNC 基础语义、主数值语义颜色、蓝牙重连与会话恢复，以及 NaN/无效帧防御。
