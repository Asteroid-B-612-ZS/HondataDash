# Changelog

## V2.0 — Semantic Dashboard and OEM Interface

V2.0 is the current generation and introduces a generational redesign of both presentation and display semantics on top of the stable V1.0 communication/data foundation.

- OEM-inspired 800×480 interface and symmetric 5+5 RPM shift indicator.
- Separate SHIFT and DFCO / OTHER_FUEL_CUT semantics.
- Trusted display memory and recovery gating for A/F, IGN and S.TRIM.
- Interpretability-weighted S.TRIM presentation.
- Dual extrema slots remain on every primary card, with semantic admission and parameter-specific retention.
- ECT/IAT rules prevent cold-start minima from contaminating useful history.
- MAP boost maxima and engine-vacuum minima use separate meaningful-context admission.
- A/F, IGN and S.TRIM extrema exclude shift, fuel-cut and strong transient contamination.
- Persistence-gated fuel-pressure alerts and short RAM diagnostic memory.
- applicationId migrated to `io.github.asteroidb612zs.hondatadash`.

## V1.0 — Original Stable Release

V1.0 corresponds to the previously validated V2.7.0 stable code baseline and is the first official generation in the consolidated public version history.

Core capabilities include FlashPro Bluetooth SPP communication, approximately 50 Hz data acquisition, an 800×480 landscape dashboard, eight primary data cards, MAX/MIN and HI/LO extrema, basic DFCO/SYNC semantics, semantic main-value colors, reconnect/session recovery and defensive NaN/invalid-frame handling.
