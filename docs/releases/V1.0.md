# HondataDash V1.0 — Original Stable Release

V1.0 corresponds to the previously validated V2.7.0 stable baseline and is redefined as the first official public generation.

Core capabilities: FlashPro Bluetooth SPP communication, approximately 50 Hz acquisition, 800×480 landscape dashboard, eight primary cards, MAX/MIN and HI/LO extrema, basic DFCO/SYNC semantics, semantic main-value colors, reconnect/session recovery and defensive NaN/invalid-frame handling.
