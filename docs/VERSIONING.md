# Public versioning

HondataDash uses generation-based public versioning from September 2026 onward.

- V1.0 = the former validated V2.7.0 stable baseline.
- V2.0 = the semantic-dashboard generation based on the final RC8 R2 candidate.

Earlier version and RC identifiers are retained only in Git history where technically necessary; they are not public releases.

Android `versionCode` values remain monotonic for technical traceability: V1.0 uses 24 and V2.0 uses 44.
